# 白內障手術 3D 互動模擬 — 設計規格

日期：2026-10-25
用途：病人衛教（診間由衛教師帶著病人操作）
參考：https://good-eye.com.tw/cataract-surgery-femto-laser-surgery/

## 1. 目標

做一個可操作的 3D 網頁，讓病人親手「做」一次白內障手術：從認識混濁的水晶體開始，經過切口、撕囊、超音波乳化、植入人工水晶體，最後看到裝好人工水晶體的眼球與術前／術後視力對比。提供「傳統手術」與「飛秒雷射輔助」兩條路線供比較。

## 2. 使用情境與限制

- 主要在診間平板或電腦上使用，由衛教師陪同。
- **必須可離線執行**：雙擊 `index.html` 即可開啟，不需安裝、不需網路。
- 支援 Windows 上的 Chrome 與 Edge；滑鼠與觸控皆可操作。
- 介面為繁體中文，字體 ≥ 20px，按鈕大，適合長輩。
- 不做語音旁白、不做音效，文字由衛教師口頭補充。
- 畫面為乾淨的醫療插畫風格，不呈現血腥寫實。

## 3. 交付物與檔案結構

```
白內障手術模擬/            ← 交付給診間的資料夾（可直接複製到平板）
  index.html               ← 雙擊開啟
  app.js                   ← 打包後的單一程式檔（一般 <script>，非 module，確保 file:// 可執行）
  content.js               ← 所有衛教文字，可用記事本修改
  style.css
src/                       ← 原始碼（開發用）
  main.js                  ← 啟動、主迴圈、視角切換
  eye/                     ← 眼球模型（各層幾何、材質、剖面、標籤）
  instruments/             ← 器械模型與「以切口為支點」的擺動邏輯
  steps/                   ← 每個步驟一個模組（共同介面見 §6）
  ui/                      ← 步驟列、文字面板、按鈕、路線選擇
  vision/                  ← 術前／術後視力對比（程式繪製插畫街景）
package.json               ← 開發相依：three、esbuild
```

- Three.js 由 npm 安裝，用 esbuild 打包成 IIFE 格式的 `app.js`，所以不需要網路，也不受 `file://` 禁止載入 ES module 的限制。
- `content.js` 不打包，以一般 `<script>` 載入，設定全域物件 `window.CONTENT`，方便非工程人員修改文字。

## 4. 流程

```
第0步 認識眼睛 → 選擇手術方式
  ├─ 傳統手術：1 切口 → 2 撕囊 → 3a 劈核 → 3b 吸除碎核 → 3c 清除皮質 → 4 植入人工水晶體 → 5 完成
  └─ 飛秒雷射：F1 雷射（自動）→ F2 取出前囊片 → 3b 吸除碎核 → 3c 清除皮質 → 4 植入人工水晶體 → 5 完成
```

完成畫面提供「換另一種手術方式再看一次」。

## 5. 各步驟規格

| 步驟 | 器械 | 病人操作 | 完成條件／畫面回應 |
|---|---|---|---|
| 0 認識眼睛 | — | 旋轉、縮放、點擊各層 | 點擊顯示該層名稱與說明；顯示「混濁水晶體 → 看出去霧霧的」；按「開始手術」後選路線 |
| 1 切口（傳統） | 角膜刀 | 按住刀子拖到 2 個閃爍標記點（主切口約 2.2mm、側切口約 1mm） | 刀尖抵達標記點範圍內即劃出切口；兩個都完成才可下一步 |
| 2 撕囊（傳統） | 撕囊鑷 | 從主切口伸入，沿虛線圓圈（直徑約 5–5.5mm）拖一圈 | 顯示進度環，囊膜隨拖曳逐段撕開；累計覆蓋 ≥ 90% 圓周即完成，前囊片自動取出 |
| 3a 劈核（傳統） | 乳化探頭（自動抵住核中央）＋劈核器（從側切口） | 沿核上的虛線拖過劈核器 | 第一刀核裂成 2 半 → 核自動旋轉 90° → 第二刀變 4 塊 |
| 3b 吸除碎核 | 乳化探頭（劈核器淡化留在眼內） | 把探頭移到碎塊旁（碎塊發光）並按住 | 碎塊被拉向探頭、冒出細小顆粒並縮小消失；顯示「已清除 n/4」；4 塊清完才可下一步。飛秒路線顯示「雷射已預先分割，超音波用量較少」 |
| 3c 清除皮質 | 灌注抽吸頭 | 無（自動播放約 5 秒） | 殘留皮質被吸乾淨，囊袋透明 |
| 4 植入人工水晶體 | 推注器 | 從主切口推進推注器 | 摺疊的人工水晶體進入囊袋後展開，兩側支撐腳固定 |
| 5 完成 | — | 自由旋轉 | 3D 眼球內為透明人工水晶體；術前（霧黃模糊）／術後（清晰）街景對比 |
| F1 雷射（飛秒） | 雷射接觸鏡 | 無（自動播放，可按播放／下一步） | 接觸鏡降下對接 → OCT 掃描光線 → 雷射光點打出 2 個切口、正圓前囊切開、核分割成 4 塊 |
| F2 取出前囊片（飛秒） | 撕囊鑷 | 開頭自動播放約 2 秒（撥開雷射切口）；之後把鑷子移到發光的圓形囊片上，按住夾起並拖向切口 | 囊片被拉出眼外即完成 |

## 6. 架構

### 步驟模組共同介面
每個步驟是一個物件，由步驟控制器依路線依序呼叫：

- `enter(scene)`：設定視角、顯示所需器械與引導（標記點、虛線、發光）。
- `onPointerDown / onPointerMove / onPointerUp(hit)`：處理操作；`hit` 是指標在眼球平面上的 3D 位置。
- `update(dt)`：動畫。
- `isComplete()`：完成時讓「下一步」亮起。
- `demoPath`：自動示範用的預錄指標路徑（時間、位置、按下與否），透過同一組 pointer 事件重播。
- `skip()`：直接把眼球狀態設為此步完成後的樣子（供「下一步」跳過與「上一步」重建狀態）。
- `exit()`：清理引導物件。

### 眼球狀態
集中在一個狀態物件（切口是否已做、前囊是否開、核碎塊數與剩餘、皮質是否清除、人工水晶體是否植入）。「上一步」與「重來此步」靠從初始狀態依序呼叫各步驟 `skip()` 重建，不需要逐步復原。

### 器械支點
器械桿身固定穿過所屬切口；指標控制的是器械尖端位置，桿身方向 = 切口點指向尖端。尖端可移動範圍限制在前房／囊袋內。

### 視角
- 第 0、5 步：可自由旋轉的 3D 剖面（切掉 1/4）。
- 手術步驟（1–4、F1、F2）：主畫面為顯微鏡俯視；左下角小視窗以同一場景的第二個攝影機顯示剖面，看得到器械深度。

## 7. 眼球模型

由程式產生幾何，不使用外部模型檔。各層使用不同顏色並可開關名稱標籤：
角膜、前房、虹膜、瞳孔、水晶體囊袋、水晶體皮質、水晶體核（混濁、黃褐色）、懸韌帶、睫狀體、玻璃體、視網膜、脈絡膜、鞏膜、視神經。

## 8. 介面

- 上方：步驟進度列（依所選路線顯示）。
- 下方：衛教文字面板，每步 2–3 句，內容來自 `content.js`。
- 按鈕：上一步、重來這一步、下一步、自動示範（本步／從頭到尾）、標籤開關、視角重置。
- 「下一步」在完成操作後亮起；衛教師仍可直接按下以跳過。
- 偏離引導時只顯示溫和提示（例如「請沿著虛線劃」），不判定失敗。

## 9. 錯誤處理

- 瀏覽器不支援 WebGL：顯示中文說明，建議改用 Chrome 或 Edge。
- 視窗大小改變、平板旋轉：畫面與小視窗自動重新配置。
- 快速連點或跳步：步驟控制器以 `skip()` 重建狀態，確保畫面一致。

## 11. 驗收

- Windows 的 Chrome 與 Edge 各走完傳統、飛秒兩條路線。
- 中斷網路，雙擊 `index.html` 仍可完整執行。
- 平板觸控操作每一步。
- 每一步的「自動示範」與「下一步跳過」、「上一步」、「重來這一步」皆正常。
- 衛教文字、器械名稱與尺寸由醫師審核（`content.js`）。
