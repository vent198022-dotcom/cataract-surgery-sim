# 白內障手術 3D 互動模擬

給病人衛教用的 3D 互動網頁：病人可以親手操作白內障手術的每個步驟，比較「傳統超音波乳化手術」與「飛秒雷射輔助手術」。

**線上使用：** https://vent198022-dotcom.github.io/cataract-surgery-sim/

## 內容
- 認識眼睛：可旋轉、點選各層構造的剖面眼球。
- 傳統手術：製作小切口 → 撕開前囊（藍色染劑、囊瓣撕開動態）→ 劈核 → 超音波乳化吸除 → 清除皮質 → 植入人工水晶體。
- 飛秒雷射：雷射如細雨打下（前囊切開、核分割、倒嵌角切口）→ 取出前囊片 → 之後同傳統手術。
- 顯微鏡視角（紅反射）＋剖面小視窗；手術中可按「旋轉觀看」3D 轉動眼球；每一步都有自動示範。
- 完成畫面有術前／術後視力對比。

## 離線使用
把 `白內障手術模擬` 資料夾複製到電腦（Windows 平板亦可），雙擊 `index.html`，用 Chrome 或 Edge 開啟即可，不需要網路。詳見資料夾內的 `使用說明.txt`。

## 修改衛教文字
所有文字都在 `白內障手術模擬/content.js`，用記事本修改引號內的文字即可。

## 開發
```bash
npm install
npm test          # 單元測試
npm run serve     # 本機預覽 http://localhost:8123（修改 src/ 會自動重建）
npm run build     # 產生 白內障手術模擬/app.js（提交前請執行）
```
程式碼在 `src/`，以 Three.js 程式產生眼球模型，esbuild 打包成單一檔案。

## 注意
本模擬為衛教示意，器械外觀與尺寸經簡化，實際手術方式以醫師說明為準。
